RWPAY CLIENT — Minecraft Java Edition 1.21.1 (Fabric)

В проекте:
- фиолетовый неоновый HUD с координатами;
- меню по Right Shift;
- переключатели HUD и компактного HUD;
- только визуальные функции, без обхода античита и вмешательства в сервер.

ВАЖНО:
Этот архив содержит ИСХОДНЫЙ ПРОЕКТ, не готовый .jar.
Для сборки нужен интернет, чтобы Gradle загрузил Fabric/Minecraft-зависимости.

Сборка в Windows:
1. Установите Java JDK 21.
2. Распакуйте архив в папку без кириллицы в пути.
3. Откройте папку проекта.
4. Дважды нажмите build.bat.
5. После успешной сборки файл появится в build\libs\rwpay-client-1.0.0.jar
6. Поместите JAR в папку .minecraft\mods вместе с Fabric API для Minecraft 1.21.1.

Открытие меню в игре: Right Shift.
