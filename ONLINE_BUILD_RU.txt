СБОРКА RWPAY ЧЕРЕЗ GITHUB ACTIONS

Этот архив содержит исходный проект и workflow для онлайн-сборки.
Это НЕ готовый JAR.

Краткий путь:
1. Создайте аккаунт/войдите на https://github.com
2. Создайте новый репозиторий (можно Public или Private).
3. Загрузите содержимое архива в корень репозитория (Add file -> Upload files -> Commit changes).
4. Откройте вкладку Actions, выберите "Build RWPAY Client", нажмите Run workflow.
5. Дождитесь зелёного статуса. Внизу страницы запуска скачайте Artifact "RWPAY-Client-JAR".
6. Внутри ZIP будет JAR из build/libs.

Если сборка красная, откройте логи и пришлите скриншот ошибки.

Примечание: при первой сборке компиляция может выявить несовместимости API. Workflow покажет точную ошибку; это не гарантия, что текущий исходник уже компилируется.
